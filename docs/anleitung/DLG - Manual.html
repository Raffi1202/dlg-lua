DLG

Widget for discus launch gliders (DLG) on FrSky radios with Ethos · Manual · Version 0.3.0 · as of 22.11.2026
FLIGHT page: flight mode on top, then flight time, launch height, vario, altitude, receiver battery and link.
In short: DLG shows the active flight mode large and in colour, measures the launch height of every launch, keeps a list of the last 50 launches and helps with all F3K tasks with working time, announcements and score. The vario is shown only: no vario tone, no thermal hint.

1. What you need

  • FrSky radio with Ethos 26.1 or newer and colour display
  • Receiver with vario / altitude sensor (usual in a DLG)
  • Telemetry on and sensors discovered (Model › Telemetry › Discover sensors)
  • For flight mode display and voice: flight modes set up and named in the model

2. Install

  1. Unzip the ZIP. It contains the package for FrSky Suite and this manual.
  2. In FrSky Suite connect the radio and install the package DLG-0.3.0.zip.
  3. Restart the radio.

Without Suite: connect the radio as USB storage and copy the folder dlg to scripts/ on the SD card.

3. Set up the screen

  1. Model › Displays › new display, layout «full screen».
  2. Choose the widget «DLG».
  3. As soon as telemetry is there, DLG assigns the sensors itself (note on top). Check in the widget menu under «Sensors».
Widget menu: Model › Displays › tap the widget. On top «Find sensors (empty only)», below the groups.

6. F3K

The F3K page helps in training and competition according to the FAI rules (Sporting Code Vol. F3, 2025). Left task and working time, right the flights of the round with the scored time, below the score.

F3K page
Poker: target fixed until reached
  • Choose the task with the arrow buttons next to its name (only when no round runs) or in the menu under F3K.
  • Tap the left field: start working time. Tap again: question «Stop working time?». Without touch: menu «F3K working time» or «Working time switch».
  • Announcements: every full minute, the last 10 seconds counted, «Working time over».
  • Poker (E): choose the target with − and + (5 s), «W» = end of working time (one attempt only). At launch the target is fixed and announced; it stays until it is reached.
  • If you switch the radio off during a round, DLG asks «Continue round?» at the next start. The time the radio was off is deducted from the working time.

7. LAUNCHES page

The last 50 launches with launch height and flight time, newest on top, the best in green. The list is kept after power off.

  • X deletes one launch (question). Later numbers move up.
  • DELETE ALL deletes the list and the lowest values (question).
  • Arrows scroll. Without touch: menu «Delete launch no.» or «Delete all launches».

10. Lua-Studio

With Lua-Studio you arrange the FLIGHT page on the PC (values, layout, limits) and transfer it to the radio. Without a studio file DLG shows the page as above.

One layout for all models: in Lua-Studio choose «For all models (default)» when transferring. The file is then called Standard.dlg.lua and applies to every model without its own file. Order: 1. choice in the menu «Studio layout», 2. the model's file (model name.dlg.lua, e.g. Segler_A.dlg.lua), 3. Standard.dlg.lua, 4. built-in page. The menu shows the entry «Default (all models)»; «automatic» shows in brackets what applies right now. Changes in the menu on the radio apply to the current model only. If a model itself is named «Standard», the file counts as its model file.

11. Troubleshooting

WhatWhat to do
Dashes instead of valuesNo telemetry or sensor not chosen: menu › «Find sensors (empty only)».
No launch height«Launch from climb» too high, or switch/flight mode for «Launch ends at» chosen wrong.
Mode announced with numberName contains none of Start/Launch, Zoom, Speed, Therm, Cruise, Land, Normal: choose the announcement in the menu.
Small: «full screen only»The widget needs a full screen display.

12. Radios

Built for all FrSky radios with Ethos and colour display (800 × 480, 640 × 360, 480 × 320, 480 × 272). Tested in the simulator on all four sizes. The test on a real radio (X18RS) follows.
