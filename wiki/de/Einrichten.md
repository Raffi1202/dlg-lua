# Einrichten

1. Modell › Bildschirme › Bildschirm mit Layout **Vollbild** anlegen, Widget **DLG** wählen.
2. Empfänger einschalten. Nach wenigen Sekunden weist DLG die Sensoren zu (oben: «n Sensoren automatisch zugewiesen»).
3. Widget-Menü öffnen (Widget unter Modell › Bildschirme antippen) und die Gruppen prüfen:

| Gruppe | Was einstellen |
|---|---|
| Sensoren | Höhe, Vario, Empfänger-Akku, Empfang (RSSI/LQ). «Sensoren suchen (nur leere)» füllt nur leere Felder. |
| Start und Landung | Start erkennen: automatisch (Steigen über «Wurf ab Steigen», ab Werk 4,0 m/s) oder Schalter. Landung: automatisch (unter «Landung unter Höhe», ab Werk 2 m, 5 s ruhig) oder Schalter. |
| Wurfhöhe | «Wurf endet bei»: automatisch (erstes Sinken, höchstens 6 s), Schalter aus (z. B. Snapflap) oder Flugphase verlassen (Nr. 1–8). |
| F3K | Aufgabe, Schalter Arbeitszeit, Poker Zielzeit, Arbeitszeit ansagen. |
| Grenzwerte (0 = aus) | Warnung und Alarm für Höhe, RX-Akku, Empfang. |
| Ansagen | Wurfhöhe, Phasenwechsel, Flugzeit nach Landung. |
| Flugphasen | Farbe und Ansage je Phase 1–8 (Ansage: automatisch nach Name, festes Wort oder aus). |
| Anzeige | Sprache: wie der Sender / Deutsch / English. |
