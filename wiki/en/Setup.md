# Setup

1. Model › Displays › add a display with layout **full screen**, choose the widget **DLG**.
2. Switch on the receiver. Within a few seconds DLG assigns the sensors (note on top: «n sensors assigned automatically»).
3. Open the widget menu (tap the widget in Model › Displays) and check the groups:

| Group | What to set |
|---|---|
| Sensors | Altitude, Vario, Receiver battery, Link (RSSI/LQ). «Find sensors (empty only)» fills only empty fields. |
| Launch and landing | Detect launch: automatic (climb above «Launch from climb», default 4.0 m/s) or switch. Detect landing: automatic (below «Landing below alt.», default 2 m, calm for 5 s) or switch. |
| Launch height | «Launch ends at»: automatic (first sink, max 6 s), switch off (e.g. snapflap) or leaving flight mode (no. 1–8). |
| F3K | Task, working time switch, poker target time, announce working time. |
| Limits (0 = off) | Warning and alarm for altitude, RX battery, link. |
| Announcements | Launch height, flight mode change, flight time on landing. |
| Flight modes | Colour and voice per flight mode 1–8 (voice: automatic by name, fixed word or off). |
| Display | Language: as the radio / Deutsch / English. |
