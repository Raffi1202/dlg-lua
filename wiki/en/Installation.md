# Installation

1. Download `DLG-<version>-share.zip` from the [latest release](https://github.com/Raffi1202/dlg-lua/releases) and unzip it.
2. In **FrSky Suite** connect the radio and install `DLG-<version>.zip`.
   Without Suite: connect the radio as USB storage and copy the folder `dlg` to `scripts/` on the SD card.
3. Restart the radio.

Requirements: FrSky radio with Ethos 26.1 or newer and a colour display, receiver with vario/altitude sensor, telemetry on.

**Update:** install the new package over the old one. Settings, launch list and a running F3K round are kept (file `scripts/dlg/daten/<model>.txt`).
**Remove:** delete the folder `scripts/dlg`.
