# Alarms

Every monitored value has two thresholds in the menu (default 0 = off):

| Value | Warning (orange, display only) | Alarm (red frame, tone/voice, vibration) |
|---|---|---|
| Altitude | above «Altitude warning above» | above «Altitude alarm above» |
| RX battery | below «RX batt. warning below» | below «RX batt. alarm below» |
| Link | below «Link warning below» | below «Link alarm below» |

An alarm repeats every 30 s («Repeat every») while it lasts. «Announce warnings too» also speaks the warnings. «Telemetry lost» is shown when telemetry was there and is gone.
