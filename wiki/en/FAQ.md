# FAQ

**Dashes instead of values?** No telemetry or no sensor chosen: menu › «Find sensors (empty only)».

**No launch height?** «Launch from climb» too high, or the switch / flight mode for «Launch ends at» is wrong.

**The flight mode is announced with a number.** Its name contains none of Launch/Start, Zoom, Speed, Therm, Cruise/Strecke, Land, Normal. Choose a fixed word for that mode in the menu (Flight modes › Voice mode n).

**Why no vario tone?** On purpose: DLG only shows the vario. If you want a vario tone, set it up in Ethos itself.

**Small field says «full screen only».** DLG needs a full screen display.
